## 📖 Overview

This repository contains the source code for the personal developer portfolio of **Mubarak Kasim Mashanu**, a Backend Engineer and Systems Architect based in Zaria, Kaduna State, Nigeria. 

The site is built with a minimalist, high-contrast dark aesthetic that prioritizes readability, instant load performance, and interactive showcase components.

---

## ✨ Features

* **⚡ Ultra-Fast Static Bundling:** Pre-bundled with Vite for sub-second page loads and zero layout shifts.
* **📱 Responsive Design:** Tailored with Tailwind CSS for mobile, tablet, and widescreen viewports.
* **💼 Production Case Studies:** Deep dives into fintech/VTU systems, logistics engines, and educational SaaS platforms.
* **📫 Direct Contact Integration:** Native email dispatch and verified social channel links.

---

## 🛠️ Tech Stack

* **Framework:** React 18, Vite
* **Styling:** Tailwind CSS, PostCSS
* **Icons:** Lucide React Icons
* **Deployment & CDN:** Vercel Global Edge Network

## ⚡ Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/mubarakkasimmaishanu/static-portfolio.git
cd static-portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
